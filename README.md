# Legio — Fortalezas de Roma

Estrategia en tiempo real para móvil: recluta legiones, marcha por los caminos y conquista aldeas, fortines y la fortaleza enemiga.

```
npm install
npm run dev        # desarrollo
npm test           # pruebas
npm run sim -- 200 # simulador de equilibrio
npm run build      # dist/index.html (un solo archivo)
python3 tools/e2e.py
```
